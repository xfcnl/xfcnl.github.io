大家好啊，我是小芬，今天又来给大家写博客了。

主要是现在已经快 11 月底，我使用那个系统马上也快 3 个月了。这 3 个月里我用了 3 个系统，没错，是 3 个系统，基本上可以说是一个月一换，但实际上算下来的话并不是，后面再慢慢讲。

## Debian

这在我心中其实挺矛盾的。Debian 的确好，但它并不兼容我喜欢的桌面环境 Niri。

一开始我用的是 Debian 加 GNOME 桌面，后来发现 GNOME 在我那台只有 4G 内存、机械硬盘的笔记本上根本不能流畅运行。于是我就琢磨着换一个，换成啥呢？换成了 Niri。Niri 好啊，平铺桌面没得说。

但它没有提供 Debian 的安装方式，Ubuntu 的倒是有，可并不适用于 Debian。怎么办呢？自己编译呗，让 AI 帮写也很方便。

而且当时我已经在使用 JavaScript 开发网站，以为它和 JavaScript 项目一样，直接一行 npm install 就能装好所有依赖。后面发现根本不行（虽然也可能是我不会用，没发现其实是可行的），但至少 Rust 是把我搞得十分懵逼。后面梁栋烨也不知道怎么想的，还给我发消息问我是不是被 Rust 搞懵了，由此可见 Rust 对我的伤害有多大。

最后我只能去 GitHub 上找别人编译好的 deb 包来装。

装好之后，不知道当时怎么想的，我把一个适用于 Arch 的主题克隆到本地，叫 AI 把里面关于 Waybar 的配置应用上去，其他的都没改。这就导致只有 Waybar 是有主题的，剩下的全都是出厂自带、丑到离谱的那套东西；就连切换壁纸，我都得打开应用启动台去搜 Waypaper。

后来气不过，我干脆换成了 Arch

## Arch (CachyOS)

梁栋烨一开始其实是推荐我用 Arch，而且是用原版 Arch。后面虽然他也推荐我用改版，但我没用，我自己找了另一个基于 Arch 的发行版，也就是 CachyOS。它做了很多优化，B 站 UP 主“开源青年”用的好像也是 CachyOS。

关于 Arch，我觉得它确实挺好用的，最大的优势就是有 AUR。上面的包非常全，很多都可以直接从 AUR 安装。但 AUR 也有不好的地方：你根本不知道谁会往上面传什么东西，之前就出现过 AUR 被投毒的情况，导致部分发行版不再内置 AUR 助手，而是需要自己去下载或者编译。当然这对我来说不算难事，毕竟在网上冲浪这么久，这种简单的障眼法我还是能识破的。

至于我为什么最后把它换掉了，核心原因还是 Arch 的 rolling update（滚动更新）。

在 Arch 里是没有版本号概念的，所有软件都保持最新。我记得当时用 Arch 遇到的第一个问题就是：更新完系统开机，我想用 Firefox 看视频，结果发现主题和界面全变了。原来 Arch 的滚动更新不只限于系统本身，整个系统的所有软件都会跟着一起更新。我不喜欢 Windows Update，是因为它强制更新系统，但不帮你更新软件；Arch 虽然不强制，而且系统和软件一起更新，这点算好一些。

另一个难受的地方是包管理器的锁定机制：安装软件时会生成一个锁定文件（lock file）。这就导致我想同时安装多个软件时，开多个终端分别下载安装是不行的，只能等前一个完全装完。虽然只是多花点时间等一等，但体验确实很不爽。

不过最主要的原因，还是 rolling update 让我的系统滚挂了两次。

第二次滚挂的时候我甚至笑了，还对着电脑屏幕录了个小视频：又滚挂了。但内心其实无比无奈。虽然这台电脑上没有重要数据（我的主力机目前还是 Windows），但它已经年岁已高，是我爸淘汰下来的，年龄可能比我都大，经不起频繁滚挂重装的折腾。

而且我毕竟还是个学生，每天睡觉前家里人都要求我必须关机。虽然有几次求过我妈没关机就去睡了，但总不能天天这样。有时候我忘了后台还在更新，顺手就直接关机了，这一关系统就彻底崩了。

第一次滚挂我还忍了，换成了 LTS 长期支持内核；结果第二次又滚挂了，我实在忍无可忍，一气之下就换了系统，改用 Fedora 了

## Fedora

到这里就要开始介绍我用过的第三个 Linux 发行版：Fedora。

说起 Fedora，其实没多少好讲的，不是说它本身不好讲，而是我的确没用多久。因为我只有周六周末可以玩电脑，机子好像是上个星期刷的，刷完之后就关了；到了这个星期，又得把一些工作流移到这台新电脑、新系统上。当然目前还没移完，只移了一部分，不过可以讲讲我移植完这部分工作流之后的感受。

配置系统这件事情我一般是交给 Agent 来做的：第一是我懒，第二是我确实不怎么熟悉，到现在只能算个 Linux 新手；而且现在都是大 AI 时代了，我需要做的就是装一个 Node.js，再通过 npm 安装 OpenCode，因为 OpenCode 内置 AI，我什么都不想干。

但这个过程不对劲啊！我在前两个系统上搞输入法、搞桌面环境很快就搞完了，怎么到你 Fedora 这里，我感觉用的时间就那么长呢？有问题啊小子，有问题。虽然目前我还说不出来具体原因，但这确实就是我对 Fedora 的初步印象
